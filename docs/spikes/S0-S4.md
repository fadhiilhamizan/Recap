## Catatan temuan teknis

- transcribe.cpp menjalankan Whisper **dan** Qwen3-ASR dalam satu runtime ggml, dengan backend CPU (dispatch per arsitektur CPU, misalnya `ggml-cpu-alderlake.dll`) dan Vulkan. iGPU Intel UHD terdeteksi.
- Qwen3-ASR di transcribe.cpp: auto-detect 30 bahasa, **tanpa timestamp**, tanpa VAD, maksimal sekitar 87 menit per panggilan. Segmentasi VAD dari pipeline Recap tetap dibutuhkan (sesuai dokumen 05).
- Rilis whisper.cpp bertag semver (v1.9.x) tidak berisi binary; binary Windows ada di tag build (`b5454`, 2026-10-06), hanya CPU/BLAS/CUDA, **tanpa Vulkan**. Untuk Vulkan di Windows, produk perlu membangun sendiri atau memakai transcribe.cpp.
